功能与积分规则

积分是 Pleadly 里的虚拟计量单位，用来计量你可用的服务次数。

积分规则

  • 积分仅在本服务内使用，不可提现、不可转让、不可兑换现金，除法律规定或另有约定外不予退款。
  • 积分兑换码为一次性使用，一经兑换即视为交付完成；一经兑换即失效。
  • 充值积分永不过期。
  • 换设备：注册账号后积分跟随账号跨设备同步；未注册时积分仅跟随当前浏览器。手机号/微信一键登录即将上线，届时跨设备同步更便捷。

使用说明

三步上手：上传材料 → 粘贴 JD → 跑分析，几分钟就能看到第一份报告。

第 1 步 · 上传你的材料

  • 进入「信息库」，上传简历 / 作品集 / 项目经历（支持 docx / pdf / txt / md）。AI 会自动分块索引。

第 2 步 · 粘贴岗位 JD

  • 进入「全面分析」，粘贴目标岗位的 JD，点击「全面分析」。

第 3 步 · 使用结果

  • 完整流程约 5–10 分钟，会产出匹配评分、简历诊断、学习计划、面试准备、定向简历等。
  • 报告自动存进「报告仓库」，关键信息自动记入「个人记忆」。

其他工具

  • 「职业定位」从技能盘点 → 市场扫描 → 路线锁定 → 落地执行四步找到方向，适合还没锁定目标岗位的情况。
  • 「离职指南」生成离职决策自检、法律核查、时间线与全套文书模板。
  • 「在职帮助」填当前在职信息，生成试用期转正、绩效冲刺、向上管理、加薪晋升的生存与成长计划。

获取积分

  • 积分面额：50 / 100 / 200 / 500 / 1000，对应 ¥25 / ¥45 / ¥80 / ¥199 / ¥369（面额越大单价越低）。
  • 购买：向作者获取一次性兑换码（小红书 pleadly 或邮箱 pleadly@163.com）。
  • 兑换：点击右上角头像进入「个人资料」，在「兑换码」输入框粘贴兑换码，点击「兑换」即可到账。

常见问题

积分、账号与隐私——你可能想知道的，都在这里。

Q：积分会过期吗？

A：充值积分永不过期。

Q：换设备积分会丢吗？

A：注册账号后积分跟随账号跨设备同步；未注册时积分跟随当前浏览器。手机号/微信一键登录即将上线，届时跨设备同步更便捷。

Q：我的简历会上传吗？

A：默认只存你本地浏览器，仅在你发起分析时发送给 AI 模型。

Q：AI 建议能保证找到工作吗？

A：不能，所有输出仅供求职参考（见免责声明）。

Q：职业定位和全面分析有什么区别？

A：全面分析针对「已明确岗位」做求职闭环；职业定位面向「还没确定方向」，帮你从自身技能与市场机会中圈定目标并制定求职计划。

Q：注册账号有什么用？

A：登录后积分跟随账号，可跨设备使用，还能设置用户名与头像。

Q：积分用完了怎么办？

A：兑换新的兑换码即可（面额 50/100/200/500/1000，对应 ¥25/¥45/¥80/¥199/¥369）。充值积分永不过期。

隐私政策

更新日期：2026-09-17

一、我们收集哪些信息

  • 你在浏览器本地填写的信息库（简历、教育、项目经历等）、岗位 JD，均默认只存储在你自己的设备浏览器（localStorage）中，不上传至我们服务器。
  • 设备标识（一个随机生成的匿名 ID）与积分余额，会存储在我们的服务端，用于记账和识别你的积分。
  • 若你选择注册账号，我们会存储你设置的账号名与密码的加密哈希（不存储明文密码）。

二、信息如何使用

  • 在你发起分析时，你选择的信息库内容与岗位 JD 会被发送给第三方大模型服务（DeepSeek）用于生成分析结果。我们不会将这些内容用于生成分析结果以外的任何用途，也不会出售、出租你的任何信息。

三、信息如何存储与保护

  • 本地信息由你的浏览器保管，你随时可清空浏览器数据删除。
  • 服务端仅存储匿名设备 ID、积分余额、账号哈希，不存储你的简历原文。
  • 我们采用行业通行的加密与访问控制措施，但无法保证绝对安全。

四、你的权利

  • 你有权要求删除账号及关联的积分数据。可删除浏览器本地数据、或联系我们来处理。

五、未成年人

  • 本服务面向年满 16 周岁的用户。未成年人应在监护人指导下使用。
